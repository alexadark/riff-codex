# Map the current system

Inspect the repository with a read-only Luna Light inventory when useful. Map user-visible flows to entry points, data boundaries, external systems, and sensitive surfaces. Distinguish verified facts from inference.

Write a concise `.riff-state/MAP.md` only when the map will be reused. Do not create a speculative target architecture, implementation plan, or exhaustive file inventory.

# Stack taste index

Read only entries matching the actual repository and current behavior. Versions and project rules win over this baseline. Prefer a project's `references/taste/stacks/INDEX.md` for its researched conventions, including existing Claude references. Codex must follow these links explicitly; no path-based autoload is assumed.

| File | Read when |
| --- | --- |
| [NowStack](nowstack.md) | The project identifies as NowStack or is a confirmed derivative using TanStack Start and Convex. |

For other stacks, preserve existing project references and use `$riff:learn-stack` when reusable conventions are missing. Do not load old React Router, Drizzle or Next.js rules merely because the project uses React. New research belongs to the invoking project; framework-wide additions require framework work explicitly in scope.
